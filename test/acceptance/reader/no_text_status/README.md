# 无文字缓存被显示为翻译失败

2026-09-30 用户报告。[异常截图](observed.png) 显示“图片文字翻译失败”，同一页面在预翻译监控中为“无文字”。`cached_result.json` 来自本次 Debug 实际运行的无文字缓存，`case.json` 记录材料哈希。

缓存解析后状态为 `noText`，恢复时 `copyWith(fromCache: true)` 清掉可选提示码。阅读页此前按提示码查文案，空提示码落入默认失败分支。现在按状态显示“未在图片中识别到文字”，使用普通信息图标，并保留手动重试。

验收覆盖实际缓存恢复后的阅读页组件、重试入口及真正失败时的提示。最终在 Debug 中从预翻译监控进入同页，确认两处结果一致。
