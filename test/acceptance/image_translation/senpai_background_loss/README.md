# 相连气泡的短对白被移到大气泡

2026-09-30 用户报告。原图中的右侧小气泡写着 `先輩～♥♥`，异常成图把“前辈～”排到了左侧大气泡，小气泡只剩被擦淡的原文。

日志和真实 OCR 都识别出了 `先輩～`，拟声词策略允许它参与翻译。翻译缓存中也有“前辈～”。问题出在排版：气泡模型把相连气泡作为一个容器，内部区域划分只保留了大气泡；两个气泡的文字起点接近，原来的按起点分区方式无法恢复小气泡。

## 验收

1. 小气泡必须有独立的可绘制区域，并覆盖原来短对白的位置。
2. “前辈～”绘制在小气泡里，大气泡绘制后续对白；两处文字不能合并到大气泡。
3. 整组译文保持完整，字号大于零。
4. 本机模型验收必须在小气泡位置检测到新绘制的深色文字，成图再次 OCR 必须在该位置识别到“前辈”。

固定快照保留修复前只返回大气泡区域的模型结果，以便未来代码改动重放。测试调用当前生产排版逻辑，不能直接使用快照中的错误区域作为期望结果。原图是用户提供的页面上部截图，本案例的模型验收范围为这张截图。
