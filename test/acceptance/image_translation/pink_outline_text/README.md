# 浅粉色渐变气泡的白描边残留

2026-10-01 用户提供原文及异常局部截图。`source.png` 是从本机阅读缓存找到的同一完整原页（保留原始 JPEG 字节），`source_detail.png` 和 `observed.png` 是用户提供的截图；图片及其中的文字仅作为测试数据。

此前只验证了灰底气泡。固定的白描边亮度阈值会让浅粉底色与白描边连通，随后整块区域被背景尺寸检查排除。旧流程在真实 CTD/LaMa 重放中留下约 78% 的白描边像素。

修复根据检测区域周围的主底色、分段局部亮度计算描边对比度，保留检测多边形支持率及黑笔画关联检查。渐变、纹理部分继续进入生产 LaMa 修复。`pipeline_snapshot.json` 是修复前重新运行真实 CTD 得到的多边形；`case.json` 保存实际 OCR 坐标和材料 SHA-256。

`evaluationRects` 对应两列实际原文，避开总外接矩形左下角经过的气泡白边；白色像素及残留阈值仅用于这个案例的评价，不参与生产描边识别。验收要求：黑字及白描边残留均小于 1%；气泡边框与旁边拟声词不能进入擦除掩码；掩码外像素不变。

快速验收还对真实字形作底色亮度及蓝、绿、米黄、淡紫色调变换，检查不同底色的描边覆盖。这些是派生压力案例，不冒充用户原始图片。完整模型重放运行真实 CTD 及生产 LaMa，不调用翻译 API。运行前需关闭旧 Debug 应用，避免 Windows 锁定构建文件：

```powershell
./tools/test_acceptance.ps1 -WithModels -CaseId pink_outline_text
```

生成背景、报告及对比预览位于 `.dart_tool/acceptance/pink_outline_text/`。最终人工验收需用户关闭旧 Debug 应用，启动修改后的应用，对这页重新翻译，并抽查其他浅色、深色及渐变气泡的残影、边框和拟声词。人工检查前不登记 `verified` 成图。
