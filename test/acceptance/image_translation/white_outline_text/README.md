# 灰底白描边黑字残留

2026-09-30 用户在 Debug 人工验收中发现。[原文截图](source_detail.png) 为白描边黑字，[异常截图](observed.png) 中原字白边仍然可见。

`source.png` 是同次运行的原页缓存（原始 JPEG 字节，保留原尺寸），`observed_background.png` 是对应的实际修复背景缓存；`case.json` 保存该气泡真实 OCR 坐标与材料哈希，`pipeline_snapshot.json` 保存真实 CTD 擦除多边形。图片和其中的文字仅作为测试数据。

原掩码覆盖黑笔画，但只覆盖约 67% 的白描边。灰底与白描边在原浅色像素阈值下连成同一个大区域，被尺寸检查排除。修复增加明亮描边识别，只接纳检测多边形充分支持、并紧邻已确认黑笔画的区域；允许描边将多个字连接起来。

验收要求：原黑字及白边残留均小于 1%；气泡外轮廓不能进入擦除掩码；掩码外画面不变。完整模型验收重新运行 CTD 和生产修复引擎，使用已录下的翻译覆盖范围，不请求翻译 API。最终在 Debug 应用里人工复查原页及其他描边文字。
